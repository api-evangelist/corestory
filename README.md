CoreStory is an AI code intelligence platform that ingests large brownfield and legacy codebases and reverse-engineers a persistent understanding of how they work — generating product requirements (PRDs), technical specifications, dependency graphs, and business-rule extractions directly from source. That intelligence is served to architects, product managers, engineers, and AI coding agents (Claude, Cursor, Copilot, Devin) to accelerate modernization, migration, maintenance, and developer onboarding. CoreStory exposes a REST API (Bearer/JWT via Clerk) and a hosted Model Context Protocol (MCP) server so agents can query project PRDs, tech specs, and codebase conversations directly. San Francisco based; raised a $32M Series A in October 2025.

**Areas:** Company · Artificial Intelligence · Code Intelligence · Legacy Modernization · Developer Tools · Code Analysis · Documentation · MCP · AI Agents

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for CoreStory: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
